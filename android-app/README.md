# Message Study Bible for Android

`MessageStudyBible.apk` is the Android phone app, built from the same source as the website
(main 3475113 + the phone intro fix: "Tap to begin" and quote Try again fixes, version 1.0.3) and signed with the app's own release key, so later builds install over it.

Download page for the phone (big button + install steps): https://kenji97works.github.io/Hear-ye-Him/android-app/

GitHub Pages sends the file as an Android app (application/vnd.android.package-archive); raw.githubusercontent.com sends it as an unknown file, which some phones refuse. The website's offline helper (sw.js) leaves everything in android-app/ alone.
