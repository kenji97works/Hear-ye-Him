# Message Study Bible for Android

`MessageStudyBible.apk` is the Android phone app, built from the same source as the website
(main 3475113) and signed with the app's own release key, so later builds install over it.

Download on the phone: https://raw.githubusercontent.com/kenji97works/hear-ye-him/main/android-app/MessageStudyBible.apk

It is linked from raw.githubusercontent.com, not the website, so the website's offline helper never handles it.
