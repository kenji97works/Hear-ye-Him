Message Study Bible

The app for Android phones

Download the app

About 47 MB. Use Wi-Fi if you can.

Then install it

Your phone shows a few warnings, because this app doesn't come from the Play Store. Each one only needs one tap.

  1. If Chrome says "File might be harmful", tap Download anyway.
  2. When the download finishes, tap Open. If you missed it, open the Files app, then Downloads, and tap MessageStudyBible.apk.
  3. If the phone says it isn't allowed to install unknown apps, tap Settings, turn on Allow from this source, then tap the back arrow.
  4. Tap Install. If Play Protect asks about it, tap More details, then Install anyway. If it asks to send the app for a scan, you can tap Don't send.
  5. Tap Open, or find Message Study Bible with the other apps.
No install at all: the same app also works in Chrome. Open the Message Study Bible website, tap the ⋮ menu at the top right, then Add to Home screen (some phones call it Install app). It gets its own icon like any other app, with no warnings.
